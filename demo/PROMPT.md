Build the landing page for a weekend game-design workshop in src/App.vue using our design system, @eltonbautista/vue (already installed). The page needs:

- a page title and a short intro
- the three workshop tracks (Board games → /tracks/board, Digital → /tracks/digital, Live-action → /tracks/larp), shown as cards; clicking anywhere on a track's card should take you to that track's page
- a sign-up form with name, email and experience level, where the attendee has to accept the code of conduct before they can submit
- a way for attendees to turn email reminders on or off; this saves immediately, there is no save button
- after they submit, ask them to confirm before the booking is made

It must be accessible (WCAG 2.2 AA) and work well with a keyboard. When you are done, run `npm run build` and fix any errors.
